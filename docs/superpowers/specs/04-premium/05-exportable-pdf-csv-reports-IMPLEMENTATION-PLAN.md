# Implementation Plan: Exportable PDF/CSV Reports

**Spec:** `05-exportable-pdf-csv-reports-design.md`
**Complexity:** M · **Estimated effort:** 3-4 days
**Depends on:** Reports module (Run 15), spec 07 (entitlements), spec 08 (optional, for extended ranges)

---

## Task 1: Add PDF generation package

**File:** `pubspec.yaml`

Add dependencies:
```yaml
dependencies:
  pdf: ^3.10.0
  printing: ^5.12.0
```

Run `flutter pub get`.

---

## Task 2: Create PDF template engine

**File:** `lib/core/reports/pdf_report_generator.dart`

```dart
class PdfReportGenerator {
  Future<Uint8List> generate({
    required List<ModuleReport> reports,
    required DateRange range,
    required String locale,
    required String? profileName,
  }) async { ... }
}
```

Builds a PDF document with:
- Header (app logo, generation date, period, profile name).
- Per-module section (chart image, summary stats).
- Footer ("Generated by Habit Tracker").

Uses the `pdf` package's `Document`, `Page`, `Widget` API.

## Task 4: Create chart-to-image renderer

**File:** `lib/core/reports/chart_image_renderer.dart`

Renders the existing `PeriodBarChart` widget to a PNG image for
inclusion in the PDF. Uses `RenderRepaintBoundary` and
`toImage()` to capture the chart widget.

## Task 6: Add export action to Reports screen

**File:** `lib/features/reports/presentation/screens/reports_screen.dart`

Add an "Export" button (FAB or app bar action) that:
1. Opens a modal bottom sheet with format picker (PDF/CSV).
2. Shows date range selector (week/month/year, premium: custom/all-time).
3. Shows preview of what will be included.
4. Triggers generation with progress indicator.
5. Opens OS share sheet with the generated file.
